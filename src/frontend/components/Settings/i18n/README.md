# Русский перевод окна настроек

Модуль переводит интерфейс irDashies на русский язык: окно настроек, основные окна приложения и виджеты на экране.

## Как это работает

- `SettingsTranslator` подключён в `src/frontend/windows/SettingsWindow.tsx`.
  Когда выбран русский язык, он обходит DOM окна настроек и через
  `MutationObserver` заменяет английские строки русскими: текстовые узлы и
  атрибуты `title`, `placeholder`, `aria-label`, `alt`. Исходные компоненты
  апстрима не меняются.
- `domTranslator.ts` — движок: нормализация ключа (крайние пробелы
  обрезаются, внутренние пробельные последовательности сжимаются в один
  пробел; крайние пробелы исходной строки сохраняются вокруг перевода),
  поиск в словаре, затем в шаблонах.
- Не переводятся (вместе с потомками): `input`, `textarea`, `code`, `pre`,
  `kbd`, `script`, `style`, любой элемент с `translate="no"`, а также текст
  внутри `.font-mono` (пути, URL, имена колонок CSV, сочетания клавиш вроде
  `Ctrl + S`). Строки без латинских букв не трогаются.
- `dictionary.ts` собирает словарь из файлов `ru/*.ts` и создаёт
  `ruTranslator`.

| Файл              | Что в нём                                                     |
| ----------------- | ------------------------------------------------------------- |
| `ru/menu.ts`      | Названия виджетов в меню                                      |
| `ru/manifests.ts` | Строки манифестов виджетов (`src/types/widgets/*.ts`)         |
| `ru/sections.ts`  | Страницы настроек (`Settings/sections/**`)                    |
| `ru/common.ts`    | Общие подписи, кнопки, единицы измерения                      |
| `ru/dialogs.ts`   | Диалоги, подтверждения, уведомления                           |
| `ru/patterns.ts`  | Шаблоны для строк, собранных из частей, и функция `pluralRu`  |
| `ru/keepAsIs.ts`  | `KEEP_AS_IS` — строки, которые намеренно остаются английскими |

## Как переключить язык

Настройки → «Общие» → «Язык»: «Русский» или «English». Выбор хранится в
`localStorage['irdashies.settingsLanguage']` (`'ru'` или `'en'`), по
умолчанию — русский. После выбора окно настроек перезагружается, чтобы
применить язык; перезапуск приложения не нужен.

## Процесс после слияния с апстримом

1. `git merge upstream/main`. Конфликты возможны только в двух строках:
   импорт и JSX-строка `SettingsTranslator` в
   `src/frontend/windows/SettingsWindow.tsx` и `LanguageSelect` в
   `src/frontend/components/Settings/sections/GeneralSettings.tsx`.
2. Тесты модуля — покажут строки манифестов без перевода:

   ```bash
   npx vitest run --project browser --no-coverage src/frontend/components/Settings/i18n
   ```

3. Отчёт о прочих непереведённых строках (JSX-текст, атрибуты, строковые
   литералы в окнах приложения, виджетах, настройках, манифестах и
   описаниях симуляторов):

   ```bash
   npx tsx tools/i18n-missing.ts
   ```

   Инструмент эвристический: в отчёте всегда есть известный фон ложных
   срабатываний — около 60 строк с фрагментами кода (`enum`, `auto`,
   значения конфигурации). Смотрите на новые строки по сравнению с
   предыдущим запуском.

4. Добавьте переводы в подходящий файл `ru/*.ts` (см. таблицу выше) и
   повторите шаги 2–3. Область сканирования включает `src/frontend/components`, `src/frontend/windows`
   и `src/frontend/App.tsx`; результаты остаются эвристическими, поэтому
   строки пилотов, телеметрии и пользовательских данных нужно проверять вручную.
   Внешний вид можно проверить в Storybook:
   `npm run storybook`, история `components/Settings/SettingsTranslator`.

### Правила словаря

- **Один ключ — одно значение.** Ключ — английская строка после
  нормализации. Если один и тот же ключ встречается в двух файлах с разными
  переводами, `buildDictionary` выбрасывает ошибку. Одинаковый перевод
  в двух файлах допустим, но лучше держать ключ в одном месте.
- **`KEEP_AS_IS`** (`ru/keepAsIs.ts`) — строки, которые не переводятся
  намеренно: имена собственные (iRacing, Le Mans Ultimate, Gantry,
  Garage 61, Twitch, YouTube), термины (iRating, Safety Rating, ABS, RPM),
  названия шрифтов и цветовых палитр, единицы вроде `px`. Отчёт и тесты не
  считают их пропущенными.
- **Шаблоны** (`ru/patterns.ts`) — для строк, собранных из шаблонных
  литералов (`Enable ${name}`, `${n} results`). Шаблон — пара
  `match` (регулярное выражение) и `replace`. Если шаблон встраивает другую
  строку (название виджета, единицу) и она неизвестна, `replace` возвращает
  `undefined` — строка остаётся английской и попадает в отчёт. Для чисел
  используйте `pluralRu(n, { one, few, many })` («1 результат»,
  «3 результата», «11 результатов»). Каждый новый шаблон сопровождайте
  примером в `dictionary.spec.ts` (блок `ruPatterns`).
- **`MONO_TRANSLATABLE`** (`domTranslator.ts`) — исключения из правила
  «текст в `.font-mono` не переводится». Сейчас это только подписи кнопки
  записи сочетания на странице «Горячие клавиши» (`Not set`,
  `Press keys...`). Добавляйте сюда строку, только если моноширинный элемент
  показывает интерфейсный текст, а не данные.
- Глоссарий и стиль: заглавная только первая буква заголовка (кроме имён
  собственных и аббревиатур), без эмодзи.
- Список виджетов в меню настроек отсортирован по английским названиям
  (`menuItems.ts`), поэтому русский порядок выглядит неупорядоченным;
  исправление требует изменения в апстриме.
- Короткие фрагментные ключи (`Use`, `An`, `Choose`, `settings`,
  `settings.`, `Uses the` в `ru/sections.ts`) действуют глобально: будущий
  апстримный текст, точно равный такому ключу, получит перевод фрагмента.
- Фразы, разбитые разметкой (`Press <kbd>F6</kbd> to unlock`), переводятся
  по частям. Подбирайте перевод частей так, чтобы вместе получался
  правильный русский порядок слов, либо добавьте шаблон.

## Известные ограничения

- Фразы, разбитые разметкой, переводятся по частям; где русский порядок
  слов ломается, нужен точечный шаблон или перевод частей под порядок.
- Пользовательские строки, совпавшие с ключом словаря, будут переведены.
  Например, профиль с именем `Default` показывается как «Стандартный», а
  профиль, название которого совпало с другой строкой словаря, будет
  показан по-русски.
- Строки примечаний к выпуску (Markdown в «Списке изменений» и «Что нового»)
  не переводятся, но строка, которая целиком совпадает с ключом словаря,
  будет переведена.
- Превью оверлеев внутри настроек (`BadgeFormatPreview`,
  `DriverNamePreview`, `RadarPreview`, превью трансляции и др.)
  переводятся только там, где их строки совпадают со словарём; остальное
  остаётся английским, как и сами оверлеи.
- Поиск по настройкам радара ищет только по английским названиям настроек —
  об этом говорит подсказка поля («Найти настройку (по-английски)...»).
- Кнопки панели Gantry «Добавить <виджет>» используют название виджета в
  именительном падеже («Добавить Расчёт топлива», «Добавить Карта
  трассы»).
- Сообщения об ошибках горячих клавиш, приходящие из основного процесса
  (`KEYBINDING_MESSAGES`, например «Shortcut unavailable—may be used by
  another application…»), остаются английскими.
- Стандартные элементы браузера/Electron (текст кнопки выбора файла
  «Choose File / No file chosen», формат даты «Изменён: 11/5/2026, 9:20 PM»)
  зависят от локали системы и модулем не переводятся.
- Строка, изменённая в апстриме, показывается по-английски, пока не
  добавлен новый перевод.
- `tools/i18n-missing.ts` — эвристика: он может пропустить строку, собранную
  во время выполнения, и показывает около 60 ложных срабатываний на
  фрагментах кода.
