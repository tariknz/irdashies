# 2026 Architecture Programme Archive

This directory preserves the review and implementation log for the architecture
programme completed in 2026.

These documents explain historical findings, measurements, decisions, and phased
delivery. They are not active task lists and should not be used to infer work for
unrelated changes. Unchecked items record proposals that were not carried forward;
any such work needs fresh evidence and standalone prioritisation.

Current architecture requirements live in
[`../../ARCHITECTURE_RULES.md`](../../ARCHITECTURE_RULES.md).

- [`ARCHITECTURE_REVIEW.md`](./ARCHITECTURE_REVIEW.md) records the original audit
  and target design.
- [`IMPLEMENTATION_PLAN.md`](./IMPLEMENTATION_PLAN.md) records delivery history
  and closure decisions, including the closure of residual Phase 2b cleanup and
  the decision not to pursue the Phase 5 worker-thread SDK loop.
